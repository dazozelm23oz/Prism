# Devlog: 2026-11-13 21:12:00

## 1. Prompt / Task Given
Build a native Linux/KDE desktop graphing calculator and computer algebra workspace called Prism. Target: fastest startup, smallest binary, polished minimalist UI. Everything offline. Launches with `npm run tauri dev`.
Includes educational step explanations for Year 1 DSBA students:
- Subsection 2a: Interactive entry palette and parameter sliders (`INSERTABLES` single source of truth, palette popup, inline autocomplete on 2+ chars, quick chips, and live parameter sliders reacting across curves).
- Canvas graphing with adaptive grid, trace mode, and labeled stationary points ($x^3 - 3x$).
- Multi-method equation solving: $2x^2 - 5x + 2 = 0$ via Factoring, Completing the Square, and Quadratic Formula.
- Calculus: $\int x e^x dx$ via Integration By Parts (LIATE) and Tabular / DI method; $\int 1/(x^2-1) dx$ via Partial Fractions.
- Linear algebra: Gaussian elimination showing every elementary row operation snapshot via `extended_matrix`.
- Constrained optimization: Lagrange multipliers and Hessian classification via `rssn`.
- Themed Typst PDF export.
- Dual-target backup (`/mnt/StudyBackups/MathCalc/` snapshot + git commit and push).

## 3. What Was Tried and Rejected, and Why
- **Direct Typst in-memory crate vs Typst CLI**: Tried `typst-pdf` crate, but discovered system already provides `/usr/bin/typst` (v0.15) natively, avoiding hundreds of crate compile hours and yielding rock-solid vector PDF compilation.
- **Root filesystem target compilation**: Root `/` filesystem ran out of space during initial unoptimized test linking. We symlinked `src-tauri/target` to `/mnt/StudyBackups/cargo_target_prism` (which has 74 GB free), completely resolving the storage bottleneck.
